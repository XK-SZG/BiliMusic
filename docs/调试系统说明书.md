# BiliMusic 调试系统说明书

> 面向**开发者**与**具备技术能力的用户**。
> 调试模式默认关闭，开启前必须完整阅读并逐项确认《调试模式使用协议 / 风险说明书 / 责任划分书》。

---

## 1. 这是什么

调试系统为 BiliMusic 提供了一组**本机 HTTP 调试接口**，可以：

- 读取运行场景快照（进程、线程、内存、数据库统计、下载队列、日志状态、标准流健康度）
- 实时读取后台日志（支持与界面一致的多条件叠加筛选）
- 查看错误系统的错误记录与错误百科
- 触发某个错误的一键修复 / 绕过
- 执行**受限**的 Python 表达式与只读诊断命令
- 执行**只读** SQL 查询

它的主要目标场景是 **Vibe Coding**：把访问令牌交给 AI 编码助手，让它自行读取运行状态、定位问题、验证修复。

---

## 2. 三道闸门

调试系统被设计成「不可能被静默打开」：

| 闸门 | 说明 |
|---|---|
| ① 协议闸门 | 必须完整阅读协议全文，并**逐项勾选** 5 条确认项；确认记录（含版本号与时间）持久化到 `backend/data/debug_consent.json` |
| ② 显式开关 | 调试模式默认关闭，必须由用户主动点击开启；关闭时立即销毁访问令牌 |
| ③ 令牌鉴权 + 能力开关 | 所有调试接口都需要 `X-Debug-Token`；「表达式执行」与「命令执行」默认关闭，需单独勾选 |

此外，协议版本号变更（`CONSENT_VERSION`）后，旧的确认记录会失效，必须重新确认。

## 3. 快速上手

### 3.1 开启

1. 打开「设置 → 调试系统」；
2. 点击「阅读《调试模式使用协议 / 风险说明书 / 责任划分书》」；
3. 完整阅读后逐项勾选确认，按需勾选「表达式执行」「命令执行」能力；
4. 点击「我已理解全部风险，开启调试模式」；
5. 复制生成的**访问令牌**（接口地址默认 `http://127.0.0.1:12180/api/debug`）。

### 3.2 连通性探测

```bash
curl -H "X-Debug-Token: <你的访问令牌>" http://127.0.0.1:12180/api/debug/ping
```

返回：

```json
{
  "ok": true,
  "message": "pong",
  "enabled_at": "2026-10-08 21:30:00",
  "capabilities": { "python": true, "shell": false, "db_query": true, "logs": true, "scene": true }
}
```

### 3.3 交给 AI 编码助手

把下面这段提示词连同令牌一起交给助手即可：

```
BiliMusic 后端已开启调试模式，接口基址 http://127.0.0.1:12180/api/debug
鉴权方式：请求头 X-Debug-Token: <令牌>
请先调用 GET /help 了解全部可用接口，再按需查阅 /scene、/logs、/errors。
```

## 4. 接口清单

所有接口均需请求头 `X-Debug-Token`（以下「协议与开关」小节除外，它们由界面自身调用）。

### 4.1 协议与开关（无需令牌）

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/debug/status?include_token=true` | 查询调试状态（含令牌，仅界面使用） |
| GET | `/api/debug/agreement` | 获取协议全文与确认项 |
| POST | `/api/debug/consent` | 提交协议确认，body `{"checklist": ["read","risk",...]}` |
| DELETE | `/api/debug/consent` | 撤回协议确认（同时关闭调试模式） |
| POST | `/api/debug/enable` | 开启调试模式，body `{"allow_python": true, "allow_shell": false}` |
| POST | `/api/debug/disable` | 关闭调试模式并销毁令牌 |
| POST | `/api/debug/token/rotate` | 轮换访问令牌（令牌疑似泄露时使用） |

### 4.2 远程调试（需要令牌）

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/ping` | 连通性与能力探测 |
| GET | `/help` | 自描述文档（便于 AI 助手自动发现能力） |
| GET | `/scene` | 运行场景快照 |
| GET | `/logs` | 读取日志，支持 `levels` `keyword` `exclude` `hide_heartbeat` `since_seq` `limit` |
| GET | `/errors` | 错误记录与错误百科 |
| POST | `/errors/{id}/repair` | 对指定错误执行一键修复 |
| POST | `/errors/{id}/bypass` | 绕过指定错误 |
| POST | `/action` | 执行受限动作 |
| GET | `/audit` | 调试审计日志 |
| DELETE | `/audit` | 清空审计日志 |
| POST | `/report-test-error` | 注入测试错误，用于验证前端弹窗链路 |

> **所有上表接口都必须携带 `X-Debug-Token` 请求头**，否则统一返回
> `403 {"detail": "调试令牌无效"}`，并在审计日志中记录一条 `auth_failed`。
>
> 令牌在以下情况会**立即失效**，需要重新获取：
> - 点击「轮换令牌」后，旧令牌作废；
> - 关闭调试模式后令牌被销毁；
> - 后端进程重启后调试模式不会自动恢复，需重新开启。
>
> 界面上的「审计日志」页签也会显示令牌失效的具体原因，不会静默失败。

### 4.3 动作（`POST /action`）

请求体统一为 `{"action": "...", "payload": {...}}`。

#### python —— 受限表达式执行

```bash
curl -X POST -H "X-Debug-Token: <令牌>" -H "Content-Type: application/json" \
  -d '{"action":"python","payload":{"expression":"platform.python_version()"}}' \
  http://127.0.0.1:12180/api/debug/action
```

- 需要开启「表达式执行」能力
- 可用对象白名单：`os` `sys` `platform` `json` `time` `datetime` `shutil` `subprocess`
  `logging` `collections` `re` `math` `statistics` `threading` `socket` `sqlite3`
  `hashlib` `uuid` `traceback` `gc` `locale` `psutil`（若已安装）
- 内置函数白名单：`len` `str` `int` `float` `bool` `list` `dict` `set` `tuple` `range`
  `min` `max` `sum` `abs` `round` `sorted` `any` `all` `enumerate` `zip` `isinstance`
  `type` `repr` `format` `map` `filter`
- 被拒绝的写法：`__import__`、`eval`、`exec`、`open`、`os.system`、`subprocess.Popen`、
  `requests`、`ctypes`、`pickle`、任何下划线开头的私有属性、对 Cookie / 凭据文件的引用

#### shell —— 只读诊断命令

```bash
curl -X POST -H "X-Debug-Token: <令牌>" -H "Content-Type: application/json" \
  -d '{"action":"shell","payload":{"command":"ipconfig /all"}}' \
  http://127.0.0.1:12180/api/debug/action
```

- 需要开启「命令执行」能力
- 命令白名单（正则全匹配，且不允许 `& | ; > < \` $` 与换行）：
  `ipconfig`、`systeminfo`、`tasklist`、`netstat`、`ver`、`where`、`ping -n`、
  `nslookup`、`dir`、`echo`
- 硬性超时 20 秒，输出截断 20000 字符

#### db_query —— 只读 SQL

```bash
curl -X POST -H "X-Debug-Token: <令牌>" -H "Content-Type: application/json" \
  -d '{"action":"db_query","payload":{"sql":"SELECT bvid, download_status FROM videos LIMIT 10"}}' \
  http://127.0.0.1:12180/api/debug/action
```

- 仅允许**单条** `SELECT` 查询
- 出现 `INSERT/UPDATE/DELETE/DROP/ALTER/CREATE/PRAGMA/VACUUM/...` 一律拒绝
- 最多返回 200 行

## 5. 安全边界

- 接口仅监听 `127.0.0.1`，不对局域网/公网开放（与后端自身的监听策略一致）
- 令牌为 32 字节 URL-safe 随机串，比对使用 `hmac.compare_digest`（防时序攻击）
- 调试模式**不会**在重启后自动恢复：进程退出即失效
- 令牌只保存在内存中，不落盘；界面仅在用户主动展开时显示
- 每一次调试请求都会写入审计日志（内存保留 500 条），并在系统日志中以
  `[调试审计]` 前缀记录
- **不会**上传任何数据：本项目没有、也不会部署任何中心化遥测服务器

### 令牌泄露了怎么办

1. 「设置 → 调试系统 → 轮换令牌」——旧令牌立即失效，无需关闭调试模式；
2. 或直接「关闭调试模式」——令牌立即销毁，所有调试接口返回 403。
