## 第二部分：BiliMusic 隐私政策 (Privacy Policy)

我们极其重视您的个人隐私与数据安全。基于 BiliMusic 的底层架构设计，我们在此向您做出**"绝对本地化"**的隐私承诺。

### 1. 绝对本地化的数据处理原则

**纯本地，零遥测**：BiliMusic 是一个完全在您的本地设备上运行的客户端程序。**我们没有、也不会部署任何中心化的遥测（Telemetry）服务器，不收集任何用户行为数据、崩溃日志、设备指纹或使用统计。**

### 2. 敏感信息的存储与流转

**2.1 账号与授权信息（Cookie）**：

当您选择在软件内扫码登录 B 站时，获取的身份验证凭证（Cookie）及用户信息（头像、UID、会员状态等）仅会**加密或明文保存在您本机的相对目录或配置文件中**。这些凭证仅用于软件代替您向 B 站请求合法的流媒体数据和播放列表，**绝对不会上传给开发者或任何第三方服务器**。

**2.2 媒体库与持久化数据**：

您的播放历史、播放列表、本地收藏夹、主题配置等数据，均仅存储于本地的 SQLite 数据库和浏览器环境的 IndexedDB 中，完全受您本人物理设备的控制。

**2.3 运行日志与诊断包**：

为便于您自行排查问题，软件会在本地写入**运行日志**（位于 `backend/data/logs/` 或安装目录下的 `data/logs/`），
并允许您主动在「设置 → 系统日志」中查看、筛选、复制、下载或删除这些日志。

日志内容可能包含文件路径、媒体标题、错误堆栈等技术信息。所有日志**仅保存在您的本机**，
本项目不存在任何自动上传行为；日志文件的保留数量与占用上限可由您自行设置，也可一键清空。

此外，软件提供「下载诊断包 (ZIP)」功能，用于您在需要时**主动**把错误信息与运行环境提供给开发者或客服。
诊断包在打包前会统一执行敏感信息脱敏，**不包含**您的 B 站 Cookie、SESSDATA、账号信息、
媒体库内容或播放记录；是否导出、是否对外提供，完全由您自行决定。

### 3. 剪贴板嗅探与监控机制专项声明

**3.1 功能原理**：为了提供便捷的"复制链接即解析"的无缝体验，本软件的后台服务（`clipboard_service.py`）会监听您操作系统的剪贴板动态。

**3.2 隐私隔离**：**我们郑重承诺，剪贴板的读取与正则表达式匹配完全、彻底地在本地离线内存中进行。** 只有当匹配到合规的"B站视频链接格式"时，软件才会进行后续解析；所有未匹配的其他任何私人剪贴板内容（如密码、聊天记录、私人文件路径）**会被瞬间丢弃，绝不会被存储、记录或外传。**

### 4. 第三方网络通信说明

您在使用 BiliMusic 过程中产生的所有网络流量，均是您的设备直接与 Bilibili 官方服务器，或由于您导入的图片直链而与相关 CDN 服务器之间的点对点通信。本软件不作为任何形式的中间人（MITM）拦截并窃取您的上游通信数据。

### 5. 数据的删除与控制

由于所有数据均在您的本地设备上，您拥有 100% 的数据控制权。如果您希望删除所有数据，只需清空软件所在目录、删除生成的数据库文件 (`backend/data/`) 以及清除相应的 AppData/Local Storage 缓存即可实现彻底销毁。
